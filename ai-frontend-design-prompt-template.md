# AI Frontend Design Prompt Template

Use this template when asking AI to generate or optimize a frontend page.

```md
You are optimizing a premium product-story frontend page.

Product:
[What is being sold]

Audience:
[Who this is for]

Core promise:
[One main promise]

Product type:
[audio product / wearable / computing device / new platform / accessory / other]

Required sections:
- Hero
- Highlights
- [Closer Look]
- [Feature Chapters]
- [Comparison]
- [Closing CTA]

Design goals:
- Product-first hierarchy
- Calm premium tone
- Short headlines
- Strong typography
- Generous but intentional whitespace
- Sparse CTA system
- Restrained motion only when it improves clarity

Avoid:
- Generic card grids
- Purple-blue AI gradients
- Too many buttons
- Long hero copy
- Repetitive section layouts
- Decorative motion without narrative value

Implementation requirements:
- Use semantic HTML
- Use CSS variables for tokens
- Make it responsive
- Keep mobile composition intentional
- Respect reduced motion

Task:
[Build / refactor / polish / redesign] this page accordingly.
```
