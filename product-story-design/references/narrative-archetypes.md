# Narrative Archetypes

This reference describes the variable layer of premium product-marketing pages: the storytelling structure.

Use this file when deciding:

- what kind of page this product needs
- which sections should appear
- how much copy to write
- whether the page should feel cinematic, practical, visionary, or comparative

Use `base-language.md` for the stable visual and interaction layer.

## The Main Rule

This design language stays stable, but its storytelling structure changes based on the product's buying psychology.

Do not choose a page structure based only on aesthetics.

Choose it based on the buyer's first real question.

## Archetype 1: Flagship Launch

Use when the buyer is asking:

`Why is this extraordinary?`

Common products:

- Pro-tier phones
- premium headphones
- premium watches

Section behavior:

- hero with emotional confidence
- highlights near the top
- closer-look or material/design section
- immersive deep-dives
- ecosystem or accessory reinforcement
- closing buy CTA

Copy behavior:

- fewer words
- higher visual dependence
- more dramatic pacing

## Archetype 2: Value Launch

Use when the buyer is asking:

`Why is this worth it?`

Common products:

- entry phones
- entry tablets
- accessible wearables

Section behavior:

- clear hero
- early practical proof
- concise highlight sweep
- straightforward deep-dives
- stronger buying help or comparison

Copy behavior:

- more explicit benefit language
- less indulgent pacing
- clearer practical explanation

## Archetype 3: Creator Device

Use when the buyer is asking:

`How does this fit into my workflow?`

Common products:

- iPad Air
- iPad mini
- laptop-tablet hybrids

Section behavior:

- hero
- highlights
- chip/performance chapter
- accessory workflow chapter
- portability and usage context chapter
- ecosystem reinforcement

Copy behavior:

- balances aspiration and utility
- often ties hardware to apps, input tools, and everyday creation

## Archetype 4: Accessory Decision Page

Use when the buyer is asking:

`Which one should I choose?`

Common products:

- stylus families
- accessories with compatibility splits

Section behavior:

- category promise
- model differences
- compatibility explanation
- feature comparison
- decision matrix

Copy behavior:

- clearer product naming
- more factual scanning language
- less cinematic emphasis

## Archetype 5: Performance Wearable

Use when the buyer is asking:

`How does this help me all day?`

Common products:

- smartwatches
- fitness wearables
- rugged body-worn devices

Section behavior:

- short emotional hero
- highlights
- life-context chapters such as health, safety, training, outdoors, communication
- style or personalization section

Copy behavior:

- practical
- scenario-based
- compact and energetic

## Archetype 6: New-Platform Manifesto

Use when the buyer is asking:

`What is this new thing, and why does it matter?`

Common products:

- spatial computers
- novel hardware categories
- platform-defining launches

Section behavior:

- declarative hero
- worldview-setting sections
- interaction-model explanation
- chapters organized by transformed behavior, not components

Copy behavior:

- more visionary
- still restrained
- teaches a new mental model before drilling into features

## Archetype 7: Sensory Experience Product

Use when the buyer is asking:

`What will this feel like?`

Common products:

- earbuds
- headphones
- sensory or immersion products

Section behavior:

- emotional hero
- film or campaign CTA
- experience-led deep-dives
- comfort, fit, ANC, sound, case, battery chapters
- comparison if multiple models exist

Copy behavior:

- sensory
- immersive
- still concise

## Archetype 8: Co-Branded Variant

Use when the buyer is asking:

`Why this edition specifically?`

Common products:

- Nike editions
- Hermès-like collaborations
- artist or brand variants

Section behavior:

- compact hero
- partnership framing
- focused differentiator sections
- faster route to purchase

Copy behavior:

- shorter page
- brand affinity language
- less feature education

## Archetype 9: Everyday Computing Device

Use when the buyer is asking:

`How will this fit into my everyday work and life?`

Common products:

- lightweight laptops
- approachable desktops
- colorful entry computing devices

Section behavior:

- hero establishes object appeal fast
- highlights arrive early
- thinness, color, portability, or desk presence matter
- workflow chapters focus on everyday capability, battery, display, calls, and continuity

Copy behavior:

- approachable
- quietly confident
- more practical than cinematic, but still premium

## Archetype 10: Workstation Computing Flagship

Use when the buyer is asking:

`Can this justify serious work?`

Common products:

- pro laptops
- workstation-class portable devices

Section behavior:

- hero is more controlled and serious
- performance proof arrives earlier and stays longer
- design sections still matter, but chip, battery, display, and workflow evidence take more page weight
- comparison and specification support become more important

Copy behavior:

- premium and focused
- more evidence-heavy
- still restrained, but less airy than a pure flagship-beauty page

## Selection Heuristic

To choose the right archetype:

1. Identify the buyer's first important question.
2. Identify whether the product benefit is visible, invisible, or worldview-shifting.
3. Decide whether the page must persuade, explain, compare, or inspire first.
4. Match the section cadence to that need.

## Archetype Checklist

Before building, ask:

- Is this page primarily selling desire, value, workflow, fit, or a new mental model?
- Is this page closer to everyday ease or professional headroom?
- Does the buyer need emotional conviction first or practical explanation first?
- Is the product best understood through object beauty, life context, invisible sensation, or comparison?

If you can answer those clearly, the page structure should follow naturally.
