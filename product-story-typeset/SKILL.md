Assess and improve typography so the interface feels calm, premium, and product-led.

## Mandatory Preparation

Invoke `product-story-design` first. If no brand context exists, run `teach-product-story` before making typography decisions.

## Diagnostic Lens

Review the current typography for:

- weak or muddy hierarchy
- body copy that is too dense or too small
- headlines that are too long or overexplained
- too many font families or weights
- poor line length and spacing rhythm
- typography that looks like generic SaaS UI instead of premium product storytelling

## Typography Logic

Premium product-story typography should feel:

- plainspoken
- confident
- highly legible
- visually quiet
- precise under close inspection

Prefer:

- one primary type family across multiple weights
- short headlines
- strong display-to-body contrast
- tight heading line-height
- measured body line-length
- sparse, edited supporting copy

Avoid:

- decorative fonts
- loud stylistic pairings
- long hero paragraphs
- tiny labels everywhere
- weight chaos
- fake sophistication through excessive letter spacing

## Improvements To Make

### Hierarchy

- Create clear roles: eyebrow, headline, subheadline, body, caption, legal.
- Use obvious size jumps between those roles.
- Keep section headlines consistent across the page.

### Sizing

- Keep body text readable and stable.
- Use larger display text only where the narrative truly needs emphasis.
- Marketing headings may use fluid scaling, but body text should remain disciplined.

### Density

- Cut copy aggressively before styling it.
- One strong line is usually better than three explanatory ones.
- If the visual already proves the point, reduce the text further.

### Rhythm

- Tighten space inside headline groups.
- Give larger breathing room between content groups.
- Keep supporting paragraphs narrow enough to stay elegant.

### Weight Strategy

- Use a restrained weight palette.
- Let size and spacing do more work than boldness.
- Reserve the strongest emphasis for the few moments that deserve it.

## Verification

Before finishing, check:

- Can the user understand the page by scanning headings alone?
- Does the body copy feel edited rather than verbose?
- Does the typography carry authority without showing off?
- Would the page still feel premium if imagery were removed?
